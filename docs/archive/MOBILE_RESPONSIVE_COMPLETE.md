## Common Mobile Features

### Breakpoints
- **1024px**: Tablet adjustments
- **768px**: Mobile landscape / tablet portrait
- **480px**: Mobile portrait

### Responsive Patterns
- Multi-column grids → Single column
- Horizontal navigation → Vertical (hamburger menu)
- Large padding → Reduced padding
- Large fonts → Smaller fonts
- Side-by-side layouts → Stacked layouts
- Fixed widths → Fluid widths (100%)
- Desktop-sized buttons → Touch-friendly buttons

### Touch Optimization
- Minimum tap target: 44x44px
- Full-width buttons on mobile
- Increased spacing between interactive elements
- Larger form inputs
- Easy-to-tap navigation links
